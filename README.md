# EGRA in Five Minutes

A coach-run, AI-marked five-minute reading and maths test for early-grade children (Urdu, English, maths), with a human in the loop. This repository is the self-contained plan: the plain-language page, every research document, the evaluation harness (scripts, results, tables) run over 187 real enumerator recordings, and a sources index of every test and paper cited.

Site: https://hyasin270.github.io/egra-five-minutes/

Child recordings, the SurveyCTO study export and transcripts are not in this repository; they are linked from the files page for the Taleemabad team.
