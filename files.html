Harness scripts (run in order to reproduce every number)

  1. audio_durations.py — ffprobe every recording, join to the child index + coach reviews, write audio/_audio_index.csv and print baseline stats. (raw)
  2. baseline_timings.py — Baseline: how long enumerators took per subtask and per child, from the SurveyCTO export. (raw)
  3. build_site.py — Build the self-contained GitHub Pages site for the EGRA-in-five-minutes plan into ./site. (raw)
  4. download_drive_audio.py — Download every file in the shared EGRA/EGMA enumerator-recordings Drive folder into ./audio. (raw)
  5. download_tips_folder.py — Download the TIPS assessment Drive folder into ./tips (Google-native files exported). (raw)
  6. harness/01_soniox_batch.py — Harness step 1: Soniox stt-async-v3 (diarised, hints ur+en) over every recording → harness/soniox/<file>.json (raw)
  7. harness/02_ground_truth.py — Harness step 2: extract per-child ground truth from the SurveyCTO export for the 206 matched recordings. (raw)
  8. harness/03_segmenter.py — Harness step 3: rule-based segmenter over Soniox diarised tokens. (raw)
  9. harness/03b_segmenter_llm.py — Harness step 3b: LLM-labelled segmentation on STT timestamps ("STT cuts, LLM labels"). (raw)
  10. harness/04_reference_reconstruct.py — Harness step 4: reconstruct the instrument's reference texts by consensus across children. (raw)
  11. harness/04b_reference_llm.py — Harness step 4b: reconstruct the reference stimuli with an LLM instead of positional voting. (raw)
  12. harness/05_human_floor.py — Harness step 5: the human floor. For every subtask, how often did the QA reviewer (second human, re-listening (raw)
  13. harness/06_reading_score.py — Harness step 6: Urdu + English reading scores from STT alone (the "cheap stack"). (raw)
  14. harness/07_maths_grade.py — Harness step 7: maths from speech. For each child, give a TEXT LLM the diarised transcript of the maths block (raw)
  15. harness/08_soniox_english_pass.py — Harness step 8: second Soniox pass on the ENGLISH block only, language hint 'en' only. (raw)
  16. harness/08b_whisper_english_pass.py — Harness step 8b: English block via OpenAI whisper-1 with language forced to 'en' + word timestamps. (raw)
  17. harness/09_english_azure_speechace.py — Harness step 9: English passage + word list — Azure Pronunciation Assessment vs SpeechAce vs Soniox-diff, (raw)
  18. harness/09b_speechace_eval.py — Re-score the cached SpeechAce responses properly: per-word verdict (quality_score < 60 = wrong) vs the enumerator's (raw)
  19. harness/10_window_scorers.py — Harness round 2, step 10: score the 60-second reading windows with the models we recommended but had not tested. (raw)
  20. harness/11_comprehension_grade.py — Harness round 2, step 11: grade the Urdu reading-comprehension answers with text LLMs. (raw)
  21. harness/12_round2_summary.py — Harness round 2, step 12: one table per experiment with the human floor and the Levenshtein baseline beside every (raw)
  22. harness/13_round2_charts.py — Harness round 2, step 13: house-style charts of the round-2 results for the board post and the site. (raw)
  23. harness/14_worked_examples.py — Harness step 14: worked examples — one page per scored window showing every artefact behind the score. (raw)
  24. harness/15_evaluation_doc.py — Harness step 15: write the ONE canonical evaluation record (harness/HARNESS_RESULTS.md) from every cached result, (raw)
  25. harness/_chain_after_segmenter.sh — (raw)
  26. harness/_patch_plan_eval.py — One-off: rewrite PLAN.html's evaluation and stack sections into the single combined record. (raw)
  27. harness/_patch_speechace.py — One-off: fold the corrected SpeechAce numbers and the Azure-vs-SpeechAce recommendation into the record. (raw)
  28. harness/_r2_audio.sh — (raw)
  29. harness/_r2_scale.sh — (raw)
  30. harness/_r2_seg_maths.sh — (raw)
  31. harness/_r2_text.sh — (raw)
  32. probes/probe1_segment.py — Probe 1: can an audio LLM segment an enumerator EGRA session into subtasks and extract the child's responses? (raw)
  33. probes/probe2_soniox.py — Probe 2: our production STT (Soniox stt-async-v3, Urdu hint, diarization) on the Urdu letter-ID slice. Run: uv run --with requests python probe2_soniox.py <wav> <lang> (raw)
